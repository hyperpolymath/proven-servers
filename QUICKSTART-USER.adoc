= proven-servers — Reader Quick Start
:toc:
:toclevels: 2

[IMPORTANT]
====
There is currently no end-user server or installable product to run. This
repository contains research/prototype source, protocol models, FFI experiments,
and binding scaffolds. Do not deploy these sources as a production server.
====

== Explore the source

[source,bash]
----
git clone https://github.com/hyperpolymath/proven-servers.git
cd proven-servers
less README.adoc
less READINESS.adoc
less PROOF-NEEDS.adoc
----

Each package README describes its own scope and evidence limits. A directory
named after a protocol does not imply a complete server or verified support.

== Optional package checks

The task entry point is https://github.com/casey/just[Just]. Idris2 and Zig are
required for compiler-backed checks; the root `mise.toml` pins Just only. The
compiler versions and full package matrix are not yet reproducibly pinned.

[source,bash]
----
just info
just deps
just build-idris
just build-zig
just test-zig
----

`just deps` reports tool availability; it does not install anything. Missing
compilers cause compiler-backed tasks to fail. See `QUICKSTART-DEV.adoc` before
running checks, and do not interpret static smoke tests as proofs or protocol
conformance.

== Not available

There is no supported `just setup`, `just run`, `just install`, container
build, deployment, or release flow. `just doctor` only reports local tool
availability and Git state; it does not repair the environment. `setup.sh` is a
non-mutating information helper. Package-specific experimental code is not an
end-user service.

For vulnerability reports, see `SECURITY.adoc` and `.well-known/security.txt`.
