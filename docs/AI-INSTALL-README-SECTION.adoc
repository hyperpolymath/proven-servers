= AI-Assisted Repository Orientation

This repository has no end-user application to install or run. It contains
research/prototype source, protocol models, FFI experiments, and binding
scaffolds; it is not a production server distribution.

If you want to inspect or contribute to the source, read
`QUICKSTART-USER.adoc` or `QUICKSTART-DEV.adoc`. Do not ask an AI assistant to
install packages, run a service, change system settings, or deploy resources
from this repository without explicit review and authorization. The current
scope and limitations are recorded in `READINESS.adoc` and
`PROOF-NEEDS.adoc`.
